## Unsay 0.1.1b (beta)

First public beta under the **Unsay** name.

### Changes
- Display name **Unsay** (mod id `unsend` unchanged)
- Edit history (`Shift+↑`/`↓`) walks all own messages still in chat (HUD backfill)
- Correct edit target when several messages share the same text (middle of three identical lines)
- Quick unsend: `Shift+Delete` / `Shift+Backspace`
- Forge: fixed chat crash `No IPlatformHelper found` (platform bootstrap)
- Fix: icons on remaining messages after Shift+Delete
- Unsent messages stay uneditable this session
- UI: Shift hover highlight; delete animation bottom-right
