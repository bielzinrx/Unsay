## Description *(Markdown)*

```markdown
# Unsay

Take back what you said.

Delete, edit, and reply to Minecraft chat messages. When you unsend or edit **your** message, every player sees the change.

---

## Delete

1. Open chat  
2. Hold **Shift**  
3. Hover your message  
4. Click trash  

Removed for everyone. Ops can moderate others’ messages.

Quick unsends: **Shift+Delete** / **Shift+Backspace**.

![Hold Shift — delete for everyone](PASTE_URL_DELETE)

---

## Edit

- Shift + pencil, or  
- Empty input + **Shift+↑** to browse your own messages  

Enter applies the edit for everyone. Empty field = unsend.

![Edit your message](PASTE_URL_EDIT)

---

## Reply

Use the reply arrow to quote a message in global chat.

![Reply with a quote](PASTE_URL_REPLY)

---

## Requirements

- Client and server both need the mod  
- Fabric API or Forge  
- See supported Minecraft versions on the **Versions** page  

---

*Unsay — take back what you said.*
```
