## Description *(Markdown do CF)*

```markdown
## Unsay

Take back what you said.

![Unsay](PASTE_URL_HERO)

Unsay lets you **delete**, **edit**, and **reply** to Minecraft chat messages. When you unsend or edit **your** message, every player sees the change.

---

### Delete

1. Open chat  
2. Hold **Shift**  
3. Hover **your** message  
4. Click the trash icon  

Removed for every player. Operators can also remove messages from others.

**Shortcuts:** `Shift` + `Delete` or `Shift` + `Backspace`.

![Hold Shift — delete for everyone](PASTE_URL_DELETE)

---

### Edit

- **Shift** + pencil on your message, or  
- Empty chat input + **Shift** + **↑** to step through your recent lines  

Send to update the same message for everyone. Empty edit unsends it.

![Edit your message](PASTE_URL_EDIT)

---

### Reply

Click the reply arrow on a message to quote it in global chat.

![Reply with a quote](PASTE_URL_REPLY)

---

### Requirements

- Client **and** server need the mod  
- Fabric (Fabric API) or Forge  
- Supported game versions: see the **Files** tab  

### Notes

- Clean UI — actions appear when you hold Shift  
- Built for multiplayer; works in singleplayer too  

---

*Unsay — take back what you said.*
```
